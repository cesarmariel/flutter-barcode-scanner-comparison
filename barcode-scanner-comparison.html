Comparativa de Plugins Flutter para Escaneo de Códigos de Barras

💡
Este análisis detallado se enfoca en velocidad de inicialización y precisión de escaneo como prioridades principales, considerando únicamente plugins que leen directamente desde la cámara del dispositivo (no de imágenes estáticas).

Resumen Ejecutivo

En Flutter existen varios plugins para escanear códigos de barras. Esta comparativa analiza los más destacados según diferentes criterios para ayudarte a elegir el más adecuado para tu proyecto.

Descripción detallada de cada plugin

barcode_scan2

▼

Es un plugin sencillo que abre la cámara para escanear un código y devuelve el resultado. Internamente, es un wrapper de librerías nativas clásicas: ZXing en Android y MTBBarcodeScanner en iOS.

  • Formatos soportados: gracias a ZXing, abarca la mayoría de códigos 1D y 2D estándares (UPC-A/E, EAN-8/13, Code 39/93/128, Codabar, ITF, QR, DataMatrix, Aztec, PDF417, etc.)
  • Velocidad de inicialización: muy rápida; prácticamente instantánea al llamar a la función de escaneo, ya que solo inicia la cámara y la decodificación nativa (no hay modelos pesados que cargar).
  • Precisión: adecuada para códigos bien impresos y condiciones normales, aunque al usar algoritmos tradicionales puede fallar con códigos muy dañados o en ángulos difíciles.
  • Facilidad de integración: muy alta – con una sola llamada asíncrona BarcodeScanner.scan() se obtiene el texto del código escaneado, manejando permisos y flashes automáticamente.
  • Nivel de personalización: limitado – el UI de escaneo es nativo predefinido (a pantalla completa), con opciones básicas como activar el flash (linterna). No permite personalizar la interfaz dentro de Flutter ni obtener flujo continuo; está pensado para "escanear y cerrar".
  • Peso del paquete: ligero – ZXing ocupa pocos cientos de KB, por lo que el impacto en el tamaño de la app es mínimo.
  • Mantenimiento: bueno – es un fork actualizado con null-safety; recibe actualizaciones periódicas (última versión publicada en 2025) tras la discontinuación del original.

flutter_barcode_scanner

▼

Plugin muy popular por su simplicidad, con API similar a barcode_scan2. Usa ZXing en Android y AVFoundation (AVCaptureSession) en iOS para decodificar.

  • Formatos: también cubre "barcodes, QR codes, etc." – en la práctica los mismos que ZXing soporta (Code128, QR, EAN-13, etc.).
  • Velocidad de inicialización: rápida y sin configuración especial (solo se debe invocar su método estático).
  • Precisión: comparable a barcode_scan2 al usar los mismos motores de detección; confiable en general, aunque hereda las limitaciones de ZXing en casos de baja calidad.
  • Facilidad de integración: excelente – proporciona métodos estáticos como FlutterBarcodeScanner.scanBarcode() que abren la cámara y gestionan permisos; por ejemplo, se puede escanear con una línea de código y obtener el resultado.
  • Personalización: baja – permite configurar algunos parámetros básicos antes de escanear (como el color del overlay de escaneo, el texto del botón de cancelar o si mostrar el icono de flash), pero no es posible insertar la vista de cámara en tu propio diseño Flutter ni modificar la experiencia más allá de esas opciones.
  • Tamaño del paquete: muy ligero (similar a barcode_scan2, se apoya en ZXing).
  • Mantenimiento: pobre – aunque sigue siendo funcional, no se actualiza desde hace ~3 años y el puntaje de mantenimiento es bajo. Puede presentar inconvenientes en dispositivos muy nuevos.

mobile_scanner

▼

Es actualmente uno de los plugins más recomendados para escaneo de códigos en Flutter. Utiliza machine learning (Google ML Kit) para detectar y decodificar códigos de barras de forma nativa, aprovechando CameraX en Android y APIs de AVFoundation/Vision en iOS.

  • Formatos soportados: prácticamente todos los formatos estándar 1D y 2D: Codabar, Code 39/93/128, EAN-8/13, ITF, UPC-A/E, Aztec, DataMatrix, PDF417, QR, etc. Por defecto detecta cualquier formato, aunque se puede restringir a un subconjunto para mejorar rendimiento.
  • Velocidad de inicialización: buena – la cámara inicia rápido con CameraX, aunque la primera vez puede requerir descargar el modelo ML Kit si no viene incluido (el plugin permite elegir incluir el modelo en la app, ~3–10 MB extra, o descargarlo bajo demanda para pesar solo ~600 KB). Después de eso, el escaneo es casi en tiempo real.
  • Precisión: alta – la detección por ML es robusta incluso con códigos rotados o parcialmente borrosos, superando a los métodos tradicionales en muchos casos. Puede leer códigos a mayor distancia o con peor iluminación que ZXing.
  • Facilidad de integración: buena – proporciona un widget MobileScanner que se puede insertar en el árbol de widgets, y un MobileScannerController para controlar la cámara. Configurar el escáner requiere ligeramente más código que los anteriores, pero sigue siendo sencillo.
  • Nivel de personalización: alto – al ser un widget, puedes sobreponer gráficos (ej. un recuadro o animación sobre la cámara) fácilmente. El controlador permite cambiar de cámara (frontal/posterior), encender/apagar la linterna, hacer zoom, definir un área de escaneo específica e incluso escanear imágenes de galería.
  • Peso del paquete: moderado – si se incluye el modelo de ML Kit dentro de la app, aumenta el tamaño unos 3–10 MB. Si no, el impacto es bajo (el código nativo pesa <1 MB y el modelo se descarga en ejecución según necesidad).
  • Mantenimiento: excelente – plugin activo y bien mantenido (actualizado frecuentemente, compatible con Dart 3, ~2000 likes en pub.dev).

google_mlkit_barcode_scanning

▼

Este plugin expone directamente la API de ML Kit de Google para escanear códigos. A diferencia de los demás, no proporciona por sí mismo una interfaz de cámara; uno debe manualmente obtener frames (por ejemplo con el plugin camera) y pasarlos al detector de ML Kit.

  • Formatos soportados: los mismos que la tecnología ML Kit ofrece – es decir, todos los formatos comunes (EAN, QR, Code 128, PDF417, etc.).
  • Velocidad y precisión: equivalentes a MobileScanner, puesto que utiliza el mismo motor de ML por debajo. Tiene alta precisión en general y funcionamiento offline en el dispositivo.
  • Inicialización: aquí depende enteramente de cómo el desarrollador gestione la cámara; el plugin en sí simplemente carga el modelo ML Kit. Puede requerir conexión la primera vez si el modelo no está integrado.
  • Facilidad de integración: baja comparada con los otros – es una librería de nivel más bajo. Se requiere más código para unir la captura de cámara con la función de reconocimiento.
  • Personalización: total – al armar tú mismo la solución, puedes diseñar la UI y comportamiento exactamente a la medida. Por ejemplo, podrías implementar un flujo de escaneo múltiple, filtros de resultados, etc., todo controlado en Dart.
  • Peso: similar a MobileScanner (usa las mismas dependencias nativas ML Kit; el plugin en sí es ligero).
  • Mantenimiento: bueno – aunque Google no lo mantiene directamente, es mantenido por la comunidad de Flutter MLKit (última versión reciente de 2025).

native_barcode_scanner

▼

Plugin orientado a alto rendimiento nativo, desarrollado por terceros, que envuelve las capacidades de reconocimiento nativas de cada plataforma. En Android utiliza la visión de Google ML Kit (similar a MobileScanner) y en iOS emplea AVFoundation directamente.

  • Formatos soportados: en Android, todos los que cubre ML Kit (Code 39, 93, 128, EAN-8/13, ITF, QR, DataMatrix, etc.), e iOS soporta la mayoría vía AVFoundation, aunque con algunas excepciones (p.ej. Codabar y UPC-A no disponibles en iOS nativo).
  • Velocidad de inicialización: muy rápida – el preview de cámara nativo se integra velozmente gracias a PlatformView. Al no mandar cada frame vía Dart, la latencia es baja incluso en dispositivos modestos.
  • Precisión: alta – combina lo mejor de cada plataforma nativa. En Android el uso de ML Kit garantiza buen reconocimiento (similar a MobileScanner). En iOS, AVFoundation tiene detección optimizada de códigos QR y varios 1D integrada en el sistema.
  • Facilidad de integración: buena – provee un widget NativeBarcodeScannerView que se puede colocar en la interfaz Flutter; los resultados de escaneo se obtienen vía streams de eventos.
  • Personalización: media – al ser un PlatformView, se puede colocar encima una interfaz Flutter (ej. dibujar un rectángulo de enfoque sobre la vista de cámara). Soporta alternar cámara, controlar el flash y otros ajustes básicos mediante métodos del plugin.
  • Peso del paquete: moderado – similar a MobileScanner: en Android se enlaza ML Kit (posiblemente de forma no incluida para no aumentar mucho la app) y en iOS prácticamente no añade peso (usa APIs del sistema).
  • Mantenimiento: moderado – versión estable publicada en 2024, con actualizaciones menos frecuentes (no tan popular, ~23 likes).

Recomendaciones por caso de uso

📱 Escaneo sencillo y esporádico

Recomendación: barcode_scan2

Para apps que necesitan escanear un código QR o de barras ocasionalmente.

Su integración ultra simple (una función que devuelve el resultado) y peso ligero facilitan añadir la funcionalidad sin complicaciones. Estas soluciones muestran una interfaz de cámara a pantalla completa, escanean el código y cierran; son ideales si no necesitas personalizar la experiencia de escaneo.

🔄 Escaneo continuo o en serie

Recomendación: mobile_scanner o native_barcode_scanner

Para aplicaciones que necesitan escanear muchos productos en un inventario o un lector de tickets.

Ambos permiten mantener la cámara activa y procesar múltiples códigos sucesivamente sin reabrir la cámara cada vez. MobileScanner destaca por su rapidez y soporte amplio – considerado "el más rápido y preciso" entre varios probados – lo que viene bien en escenarios de volumen alto. NativeBarcodeScanner es también muy rápido y podría darte unos FPS extra en dispositivos Android antiguos gracias a su menor overhead nativo.

🔍 Condiciones desafiantes

Recomendación: mobile_scanner

Si la prioridad es la precisión en condiciones desafiantes (códigos dañados, muy pequeños, baja iluminación).

Los motores basados en machine learning (como los de mobile_scanner y ML Kit) tienden a rendir mejor que ZXing en esos casos. ML Kit aprovecha técnicas de visión artificial para detectar códigos aunque partes estén borrosas, y tiene heurísticas para orientaciones variadas.

🎨 Personalización de UI

Recomendación: mobile_scanner o google_mlkit_barcode_scanning

Si necesitas personalizar la interfaz de escaneo (recuadros, animaciones, controles personalizados).

Estos plugins te permiten poner la vista de la cámara dentro de tu diseño Flutter y superponer elementos. Mobile_scanner da más flexibilidad en controlar la lógica desde Dart, mientras que google_mlkit te da control total pero requiere más implementación.

⚖️ Tamaño de app mínimo

Recomendación: barcode_scan2

Para proyectos que requieran poca carga y compatibilidad amplia.

Las soluciones basadas en ZXing (barcode_scan2, etc.) tienen la ventaja de no inflar el tamaño de la app ni depender de componentes externos. Añaden menos de 1 MB y funcionan offline directamente.

Mejor opción general

🏆

MobileScanner se perfila como la opción más equilibrada y potente para la mayoría de proyectos.

Ofrece gran velocidad y precisión gracias a ML Kit, soporta todos los formatos habituales, es fácil de integrar y altamente personalizable, con una comunidad activa respaldándolo.

Ejemplo de integración: mobile_scanner

▼

Este es un ejemplo básico de cómo implementar mobile_scanner en una aplicación Flutter:

import 'package:flutter/material.dart'; import 'package:mobile_scanner/mobile_scanner.dart'; class BarcodeScannerPage extends StatefulWidget { @override _BarcodeScannerPageState createState() => _BarcodeScannerPageState(); } class _BarcodeScannerPageState extends State { MobileScannerController controller = MobileScannerController(); bool _isScanning = true; @override Widget build(BuildContext context) { return Scaffold( appBar: AppBar(title: Text('Scanner'), actions: [ IconButton( icon: Icon(_isScanning ? Icons.stop : Icons.play_arrow), onPressed: () { setState(() { _isScanning ? controller.stop() : controller.start(); _isScanning = !_isScanning; }); }, ), IconButton( icon: ValueListenableBuilder( valueListenable: controller.torchState, builder: (context, state, child) { switch (state) { case TorchState.off: return Icon(Icons.flash_off); case TorchState.on: return Icon(Icons.flash_on); } }, ), onPressed: () => controller.toggleTorch(), ), IconButton( icon: Icon(Icons.flip_camera_ios), onPressed: () => controller.switchCamera(), ), ]), body: Stack( children: [ MobileScanner( controller: controller, onDetect: (capture) { final List barcodes = capture.barcodes; for (final barcode in barcodes) { // Tu lógica cuando se detecta un código print('Barcode found! ${barcode.rawValue}'); } }, ), // Overlay para guía de escaneo Center( child: Container( width: 250, height: 250, decoration: BoxDecoration( border: Border.all( color: Colors.green, width: 3.0, ), borderRadius: BorderRadius.circular(12), ), ), ), ], ), ); } }
